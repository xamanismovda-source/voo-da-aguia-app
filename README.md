# Vôo da Águia

Aplicativo oficial do **Xamanismo Vôo da Águia**, desenvolvido para Android.

O aplicativo reúne oráculos, eventos online, práticas, conteúdos de aprendizado, diário, recados, bússola xamânica e o Guia Local.

## Instalação

As versões oficiais do aplicativo são disponibilizadas na seção **Releases** deste repositório. Cada versão acompanha um arquivo SHA-256 para conferência do APK.

## Atualizações

Quando houver uma nova versão publicada, o próprio aplicativo poderá apresentar o aviso e direcionar para o endereço oficial de download.

## Segurança

Baixe o APK somente pelas versões oficiais publicadas neste repositório.
